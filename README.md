# Sora2-Unlimiter

Одностраничное демо «Уникальный чат-парсер» для безопасной офлайн-симуляции работы с чатами. Интерфейс запрашивает номер, создаёт псевдосессию, показывает список чатов, позволяет настроить админ-панель сканирования и выгружает отправителей последних сообщений с дата-центром 1.

## Функции
- Имитация создания сессии по номеру.
- Список чатов с количествами сообщений.
- Админ-панель с настройками глубины, фильтрами (DC=1, боты, ключевые слова, минимум длины сообщения, дедупликация).
- Сканирование последних сообщений и выгрузка юзернеймов (DC 1) в текстовый файл.
- Полностью локальная работа — без сетевых запросов.

## Запуск
Откройте `index.html` в браузере. Дополнительная сборка или сервер не требуются.
